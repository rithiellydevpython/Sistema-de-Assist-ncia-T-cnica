Sistema de Gerenciamento para Assistência Técnica
📌 Visão Geral

O Sistema de Gerenciamento para Assistência Técnica é um projeto em desenvolvimento que tem como objetivo criar uma aplicação web voltada para o controle completo de processos em uma loja de conserto de celulares.

O sistema busca otimizar o gerenciamento de clientes, aparelhos, serviços, produtos e estoque, oferecendo uma solução prática e organizada para o dia a dia da assistência técnica. Além disso, o projeto serve como base de estudo e aprimoramento técnico em desenvolvimento full-stack, com foco em Python, FastAPI e front-end web.

🎯 Objetivos do Projeto
Desenvolver uma aplicação web funcional que simule um sistema real de assistência técnica.
Servir como projeto de estudo e portfólio profissional.
Aplicar conceitos de front-end, back-end e persistência de dados.
Criar uma base escalável para futuras melhorias, como relatórios, análise de dados e autenticação avançada.
🧩 Funcionalidades Implementadas e em Desenvolvimento
Funcionalidades Atuais
Front-end funcional
Tela de login separada para segurança das informações.
Dashboard inicial com visão geral do sistema.
Menu lateral com acesso a cadastros e consultas.
Cadastro e Consulta
Cliente, Aparelho, Serviço e Estoque: cadastro e consulta funcionando.
Controle de estoque com registro de retiradas por data e quantidade.
Estrutura de Dados
Inicialmente utilizando arquivos JSON para persistência.
Futuro: integração completa com banco SQLite via FastAPI.
Funcionalidades Planejadas
Implementar edição e exclusão de Cliente, Aparelho, Serviço e Estoque.
Desenvolver consultas completas de Vendas.
Criar relatórios detalhados e análise de dados de vendas e estoque.
Implementar autenticação de usuários e permissões de acesso.
Aprimorar interface com CSS/JS, responsividade e experiência do usuário.
Substituir confirm() por modais personalizados interativos.
🛠️ Tecnologias Utilizadas

Front-end

HTML5 – Estrutura semântica do sistema.
CSS3 – Layout, estilos e responsividade básica.
JavaScript – Funcionalidades interativas e manipulação de dados.

Back-end

Python + FastAPI – Lógica do sistema, processamento de dados e integração com SQLite.
JSON – Armazenamento inicial de dados (clientes, aparelhos, serviços, estoque).
Futuro: Banco de dados relacional completo para persistência avançada.
